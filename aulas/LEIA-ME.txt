Prof. Serufo — Site SPA

COMO ABRIR
  cd pasta-do-site
  python -m http.server 8080
  Abra http://localhost:8080

ABA OUTROS (PDFs)
  - Coloque os PDFs dentro de pdfs/ (pode usar subpastas)
  - A listagem é automática (sem script)
  - Cada arquivo mostra o nome e uma miniatura da 1ª página
  - Botão "Atualizar" varre a pasta de novo
  - Se a listagem automática falhar, use "Selecionar pasta pdfs"
