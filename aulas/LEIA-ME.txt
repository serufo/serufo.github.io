Prof. Serufo — Site SPA (GitHub Pages)

HOSPEDAGEM
  Este site é feito para GitHub Pages (*.github.io).

ADICIONAR PDFs
  1. Coloque os PDFs em pdfs/ (com subpastas se quiser)
  2. git add pdfs && git commit -m "PDFs" && git push
  3. Espere o deploy e abra a aba Outros (ou clique em Atualizar)

  A listagem é automática via API do GitHub.
  O repositório precisa ser público.

SE A LISTAGEM FALHAR
  No index.html, descomente e preencha:
    <meta name="github-owner" content="seu-usuario" />
    <meta name="github-repo" content="nome-do-repo" />

TESTE LOCAL
  python -m http.server 8080
  (listagem local por HTML do servidor; no GitHub Pages usa a API)
